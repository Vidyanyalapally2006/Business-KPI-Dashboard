# Business Sales & Financial KPI Dashboard

## Overview

An interactive Business Sales & Financial KPI Dashboard built using Microsoft Power BI to provide an executive-level view of sales performance, profitability, products, regions, and yearly trends.

The dashboard transforms financial sales data into clear business KPIs and visual insights that can support data-driven decision-making.

## Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- Data Visualization
- Business Analytics

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin %
- Units Sold
- Average Sales per Unit

## Dashboard Features

- Executive KPI cards
- Sales by Product analysis
- Sales by Country analysis
- Year-wise Sales Trend
- Year filter
- Segment filter
- Interactive cross-filtering
- Business-focused visualizations
